# Markshot

Windows 截图 / 贴图 / 批注 / 截图翻译工具，交互对标 PixPin 的基础工作流。

> 当前版本 **0.8.17**（从 0.8 起按两位小数递增：0.8.01、0.8.02…）。长截图、录屏不在本阶段范围。

> 原位翻译：打开工具栏的翻译开关后，选区里的文字会像 Chrome 网页翻译一样直接替换成译文（保留位置、底色、颜色、字号），复制/保存/贴图得到的就是译文图。贴图右键也可“原位翻译 / 显示原文”。

## 已实现

### 截图
- 全局热键唤起，冻结当前屏幕并压暗，框选后保持原画面
- 区域选择、8 向手柄缩放、拖动移动、尺寸标签
- 框选完成后才弹出工具栏；加粗蓝色边框，边缘/手柄都可拖动重设区域
- 拖拽选区时按住 `空格` 可临时移动选区（Photoshop 手感）
- 工具栏分组收纳：主栏只有图形、画笔、箭头、文字、序号、马赛克、橡皮；没有单独的选择按钮
- 图形/画笔/箭头/文字/马赛克带下拉箭头，可切换矩形/椭圆、画笔/荧光笔、箭头/直线、文字字号、马赛克/水印
- 激活工具后，光标移到同类已有元素上会高亮，点击即可选中并继续编辑；再次点击已激活的工具会取消激活
- 取消所有工具后鼠标回到箭头，可拖动贴图窗口
- 当前工具的样式与参数在下方副栏，包括填充、粗细、圆角、颜色；选择已创建元素时继续显示对应设置
- 已创建元素的调整框支持 8 向缩放和旋转手柄；按住 `R` 拖动可整体缩放，`E` 可在绘制中旋转，`Ctrl` 可给矩形加圆角，右键取消当前创建
- 画笔/荧光笔笔迹只生成像素，不参与选中；图形/箭头用十字光标，文字用输入光标，画笔/橡皮用圆形光标
- 工具栏最左侧有拖动块；按钮为无底色图标
- 各标注工具有对应光标（框选/画笔/图形/文字/橡皮等）
- 悬停自动框住鼠标下的 UI 元素（文字、图片、表格、按钮…）或窗口，框随鼠标经过的元素平滑变化，单击即截取；
  滚轮在元素和外层之间切换。设置 → 保存与识别 → 截图识别 可分别关掉元素识别 / 窗口识别
- 显示鼠标：截图里包含鼠标指针，`Ctrl+M` 切换（会记住，按键可改）
- 辅助线：单按 `Alt` 显示 / 关闭以鼠标为中心、贯通屏幕的十字线（按键可改，选区前后都可用）
- 放大镜实时显示像素与色值，`C` 复制，`Shift` 切换 RGB / HEX
- 方向键 1px 微调，`Shift + 方向键` 10px
- `R` / `Shift + R` 载入最近 10 次截图区域
- 多显示器虚拟桌面抓取（同一缩放比例下）
- 框选后可复制、另存为、快速保存、贴图、翻译

### 批注
- 矩形、椭圆、箭头（尖头 / 线形 / 三角 / 双向）、直线、折线、画笔、荧光笔、马赛克、文字、序号
- 折线在箭头按钮的副栏里：单击放拐点（也可拖出一段），双击 / `Enter` / 右键结束，`Backspace` 撤回一个拐点，`Shift` 45°，`Esc` 放弃
- 选择 / 移动 / 删除已有批注，改颜色与线宽；橡皮擦只擦掉划过的部分（可调透明度做半擦除），可撤销
- 截图转贴图 / 进图片编辑器后，撤销记录接着用：`Ctrl+Z` 能撤回截图时画的批注；退出贴图编辑再进来也还在
- 撤销 / 重做，颜色盘，细 / 中 / 粗三档线宽
- 文字批注：文字工具下单击空白处直接输入，单击已有文字进入编辑、拖动可移动；所见即所得（编辑时就是最终效果）
  - `Enter` 完成，`Shift/Ctrl + Enter` 换行，`Esc` 完成，内容清空即删除
  - 字号、颜色、**粗体**（`Ctrl+B`）、背景标签、描边都可在输入时调整；输入中滚轮改字号
  - 选择状态下双击文字（或选中后按 `F2`）进入编辑
- 所有元素（含画笔笔迹）都有透明度：激活工具后 `Ctrl + 滚轮` 预设（每格 5%，各工具分别记忆），
  选中元素后 `Ctrl + 滚轮` 调它的透明度；自定义颜色按钮按透明度在棋盘格上预览，旁边显示百分比，自选色板的透明度即元素透明度
- 选中元素后直接滚轮调粗细 / 字号 / 序号大小（区域马赛克为程度）；新画好的元素自动处于选中状态，可直接调整
- 马赛克工具：类型 [区域 | 画笔]、程度（画笔另有粗细）；水印在文字按钮的展开项里：大小、倾斜、透明度、颜色，按住拖动移动、双击编辑；马赛克不会打码水印
- 工具按钮的展开项选了别的样式（椭圆、荧光笔、直线、画笔马赛克、水印），按钮就换成该工具；`Tab` 在同一按钮的样式间切换，
  选中元素时切换样式会直接把该元素换成新样式（矩形 ↔ 椭圆、直线 ↔ 箭头、画笔 ↔ 荧光笔）；图形工具快捷键 `M`（可改）
- 选中的元素（画笔类除外）`Ctrl+C` / `Ctrl+V` 复制粘贴，`Delete` 删除；水印工具下 `Delete` 删除水印
- 设置“复制图片文件”：复制截图/贴图时同时放一个 PNG 文件到剪贴板，可直接在文件管理器粘贴
- 橡皮擦：粗细、透明度（透明度低于 100% 时只把笔迹擦淡）
- 文字描边：粗细为 0 即关闭
- 任何拖动（绘制、移动、缩放、旋转、拖文字、拖水印、调整截图区域）未松手时按右键 = 撤回这次操作
- 贴图上的批注只画在图片范围内；贴图的批注工具栏可单独拖走，贴图不动
- 贴图上按住 `Alt` 显示放大镜（同截图），松开即关；拖动贴图未松手时按右键回到原位
- 未展开批注栏时贴图上 `E` = 逆时针 90°、`T` 置顶、`L` 锁定；其它工具字母会直接打开批注栏
- 方向键微调贴图位置（Shift 10px）；拖动贴图时按住 Shift 只水平或竖直移动
- 托盘图标中键单击直接截图；托盘右键菜单为同款暗色圆角菜单
- 截图框四角内侧的小圆点：往中心拖动给截图加圆角（输出 PNG 圆角透明，贴图也是圆角）；鼠标移到截图框线上会浮出尺寸输入框
- 设置 → 贴图窗口：贴图阴影大小、颜色、透明度
- 打开截图时，变暗效果从屏幕边缘向鼠标聚拢；退出时从鼠标处反向变亮；转为贴图时贴图立即出现（不闪烁），
  屏幕从贴图轮廓向外变亮，贴图上划过一道光
- 截图左上角的尺寸标签可直接点击修改宽高（Enter 应用）
- 截图区域内按鼠标中键直接贴图；选好区域后右键 = 重新截图；还没选区域时按住右键拖动 = 手绘（套索）截图，按住 Shift 画直线段，
  截出的图按路径抠出（外部透明，贴图阴影沿形状）
- 全局快捷键可设为鼠标中键 / 侧键（可配合 Ctrl / Alt / Shift）
- 保存图片后询问是否打开所在文件夹（弹窗里或设置里可关闭）
- 贴图翻转 / 旋转有快速过渡（旋转以贴图中心为轴）；调节阴影时已打开的贴图实时预览
- 批注栏按钮可长按拖动排序（被拿起的按钮抖动，旁边按钮滑开让位）；设置 → 保存与识别 → 批注栏按钮 里按截图模式 / 贴图模式
  分别单击开关某个按钮（变暗 = 不显示）、长按拖动排序
- 右键菜单只显示当前用得上的项
- 调整框四角外侧有弯曲双向箭头，按住顺/逆时针拖动即旋转；文字输入时也是同样的调整框（框边拖动移动、手柄缩放、弯箭头旋转），不打断输入
- 画笔/荧光笔/画笔马赛克画完不进入选中状态，可连续书写
- 撤销/重做覆盖所有编辑：绘制、移动、缩放、旋转、改样式、改文字、删除（`Ctrl+Z` / `Ctrl+Y`）
- 批注在复制、保存、贴图时合成进图片；翻译使用未批注的原图

### 贴图
- 无边框置顶窗口，按截图位置钉在屏幕上
- 拖动空白处移动、滚轮缩放、`Ctrl + 滚轮` 透明度（未激活批注工具时，编辑中也一样）、按住中键拖动移动、中键单击重置
- 图片里的文字可直接选中复制（本地 OCR 文字层）：文字上为文本光标，拖动选中、双击选整行、`Ctrl+C` 复制；按住 `Alt`（可改）无视文字拖动贴图
- `F` 只重置大小、透明度和旋转/翻转，保留批注；右键菜单可“清除批注内容”
- 截图时画的批注贴图后仍可再次编辑
- 双击空白 / `Esc` 关闭，`T` 置顶切换，`L` 锁定，边框颜色随状态变化
- 右键菜单：复制、另存为、翻译、编辑标注、置顶、锁定、鼠标穿透、重置、关闭
- 按 `空格` 在图片下方弹出与截图一致的标注工具栏，直接在贴图上编辑；再按空格或 `Ctrl+S` 写回
- 绘制中按住 `空格` 可整体移动当前图形，松开继续画；没有绘制时 `空格` 开关工具栏
- 工具栏没有额外关闭按钮；取消所有工具后可直接拖动贴图
- 截图工具栏右侧提供文字识别、关闭、贴图、保存、复制、原位翻译开关（开关状态会被记住）
- 同时最多保留 20 张贴图；关闭后只保留最近 10 张历史，可从托盘恢复
- 多选贴图：`Shift` + 单击加选（先点 A 再 Shift+点 B 即两张都选中），`Ctrl` + 单击减选；选中的贴图有蓝色虚线框，
  拖动其中一张一起移动，方向键一起微调，`Esc` / 右键「关闭选中的贴图」一起关闭；单击其中一张（不拖）取消多选
- 鼠标穿透后可从托盘“取消所有鼠标穿透”
- 剪贴板没有图片时，可把纯文本渲染成卡片贴出

### 图片编辑器
- 入口：托盘「图片编辑器…」、截图工具栏和贴图工具栏最右边的编辑按钮、贴图右键菜单、长截图结束时
- 打开或拖入图片（PNG / JPEG / WebP / BMP / GIF / TIFF / ICO），全部批注工具可用，批注一直可编辑
- 尺寸（可锁定比例）、左右转 90°、水平 / 垂直镜像、任意角度旋转；矩形裁切、路径裁切（手绘，路径外透明）、梯形校正（拖四个角）
- 调色：亮度、对比度、饱和度、透明度、灰度、反色，可重置；所有操作都能撤销（Ctrl+Z）
- 保存（PNG / JPEG / WebP / BMP / TIFF）、复制、贴到屏幕（Ctrl+T，批注在贴图上仍可编辑；从贴图进入时替换原贴图）；未保存时关闭会询问
- Ctrl+滚轮缩放、滚轮滚动、中键拖动画面，Ctrl+0 适应窗口，Ctrl+1 实际大小

### 长截图
- 截图选好区域后点工具栏的「长截图」（▾ 或 Tab 切换竖向 / 横向）：在框内滚动，新出现的内容自动拼接，来回滚动不会重复；
  固定不动的页头 / 底栏只保留一份。旁边的小窗实时显示拼好的长图
- 框下工具栏：竖向 / 横向、编辑（Enter，进入图片编辑器）、复制、保存、取消（Esc，回到截图）。长截图进行期间 Tab 和 Esc 由 Markshot 接管

### 录屏（from SketchPlayer）
- 托盘菜单「录屏」、截图工具栏的录屏按钮（录制选中的区域）或设置里的录屏快捷键打开；蓝色录制框（录制中变红、暂停变琥珀色），
  拖边框移动、八个把手调大小，框内照常操作电脑；框线画在区域外面，不会录进视频
- 工具栏：时间 · 帧率（15/24/30/60）· 尺寸（物理像素，可直接填，三档常用尺寸）· 延时（1–10 秒倒计时）· 开始 / 停止 · 暂停 ·
  系统声音 · 麦克风 · 操作录制 · 重录 · 退出；工具栏紧贴框线放在区域外，不会录进去；区域铺满屏幕、工具栏只能压在区域里时，
  录制期间它会被排除在录像之外（注意：被排除的窗口在远程控制 / 屏幕共享画面里也看不到）
- 停止后录制框原地变成预览：时间条拖三角剪头尾、倍速、静音，保存 MP4 / GIF（流畅 / 清晰 / 高清 + 帧率），
  或「复制」直接把视频文件放进剪贴板（可粘贴到聊天 / 文件夹）；没保存就退出会先询问
- 打开时屏幕先暗一下，把视线带到录制框；暂停时暂停按钮琥珀色闪
- 操作录制：框里左下角实时显示按下的键盘 / 鼠标键（组合键、连按 ×n），同样录进视频
- 任务栏单独一个「Markshot 录屏」：点它收起 / 展开录屏界面（录制照常）；右键菜单有 开始 / 停止 / 暂停 / 继续 / 退出录屏，关闭窗口 = 退出录屏
- 托盘菜单的录屏项跟着状态变：录屏 → 开始录屏 / 停止录屏 / 暂停 · 继续录屏 / 显示录屏 + 退出录屏
- 从截图转录屏时不再变暗，只是框线变成录屏的蓝色；重录回到调框状态，按「开始」才录
- 编码 / 导出用随附的 ffmpeg（自动选用 NVENC / QSV / AMF / Media Foundation 硬件编码，失败退回 x264）；声音用 WASAPI
- 这一功能移植自作者的另一个项目 SketchPlayer 的录屏（见其《技术文档_录屏》）

### OCR 与翻译
- OCR 使用 RapidOcrNet（ONNX Runtime + PP-OCRv5），与 PixPin 同属 PaddleOCR 模型体系；本地推理，图片不出本机
- 翻译服务为任意 OpenAI 兼容 `/chat/completions` 接口（DeepSeek / OpenAI / Moonshot / Ollama / LM Studio / one-api 等）
- 原文可编辑，译文对照显示；支持复制译文、把译文贴到屏幕
- 识别结果保留排版：同一行的文字合成一行，表格的列用 Tab 分隔（可直接粘贴进表格软件），缩进和段落空行保留
- 目标语言可临时切换，默认语言可在设置中修改

### 其他
- 托盘「贴图历史…」：最近关闭的 30 张贴图缩略图，单击重新贴出（本次运行中关闭的连批注和缩放一起恢复），右键复制 / 删除，可清空
- 托盘「导出诊断信息」：把日志、配置（不含 API Key）和系统信息打包到桌面，方便反馈问题
- 设置 → 保存与识别：开机自动启动
- 翻译 API Key 用 Windows 账户加密保存（换电脑 / 换用户需要重新填写）
- 设置 → 样式：主题（暗色 / 浅色 / 跟随系统，浅色下所有界面换成浅色）、界面大小（中 / 大，大档按钮和文字整体大一号）、贴图阴影；选择后立即预览
- 托盘常驻、单实例、全局热键可配置、开机不自动启动
- 日志写入 exe 同目录 `logs/app.log`
- 配置支持漫游目录与便携模式（exe 同目录 `config.json` 优先）

## 快捷键

### 截图态

| 操作 | 快捷键 |
| --- | --- |
| 唤起截图 | `F1`（可在设置中修改） |
| 复制并退出 | `Enter` / `Ctrl + C` / 双击选区 |
| 另存为 | `Ctrl + S` |
| 快速保存 | `Ctrl + Shift + S` |
| 贴图 | `F3` |
| 翻译 | `Ctrl + Q` |
| 全选当前屏幕 | `Ctrl + A` |
| 撤销 / 重做 | `Ctrl + Z` / `Ctrl + Y` |
| 选择 / 移动批注 | `V` |
| 切换工具 | `B` 画笔、`V` 选择、`E` 橡皮、`T` 文字、`S` 序号、`L` 直线/箭头（可在设置里改） |
| 工具字母别名 | 默认 `B/V/E/T/S/L`；设置 → 标注工具快捷键可修改 |
| 绘制中移动当前图形 | 按住 `空格` 拖拽 |
| 删除选中批注 | `Delete` / `Backspace` |
| 载入最近截图区域 | `R` / `Shift + R`（向前 / 向后） |
| 复制像素颜色 | `C`（`Shift` 切换 RGB / HEX） |
| 逐层退出 | `Esc`（先退批注选择，再退工具，再退选区，最后关窗） |
| 移动选区 | 方向键，`Shift` 加速；选中批注时移动批注 |

### 贴图窗口

| 操作 | 快捷键 |
| --- | --- |
| 移动 | 鼠标拖动 |
| 缩放 / 透明度 | 滚轮 / `Ctrl + 滚轮` |
| 重置缩放与透明度 | 鼠标中键 |
| 编辑标注 | `空格` |
| 鼠标穿透 | 设置中配置（默认 `Ctrl+Alt+M`） |

| 文字选择辅助键 | 设置中配置（默认 `Alt`，按住拖动贴图） |

| 复制 | `Ctrl + C` |
| 另存为 | `Ctrl + S` |
| 置顶切换 / 锁定 | `T` / `L` |

> 贴图快捷键可以在设置中留空；留空后不注册全局贴图热键，仍可通过托盘“贴图剪贴板”使用。

## 打包

双击 `tools\package.cmd`（或 `powershell -ExecutionPolicy Bypass -File tools\package.ps1`）：先检查依赖，缺什么会给出安装命令，
然后在 `dist\` 生成 `Markshot-<版本>-portable.zip`（便携版，解压即用）和 `Markshot-Setup-<版本>.exe`（安装包）。
`-NoInstaller` 只打便携版，`-NoPortable` 只打安装包。

| 依赖 | 用途 | 安装 |
|---|---|---|
| .NET 8 SDK | 编译（必需） | `winget install Microsoft.DotNet.SDK.8` 或 https://dotnet.microsoft.com/download/dotnet/8.0 |
| Inno Setup 6 | 生成安装包 | `winget install JRSoftware.InnoSetup` 或 https://jrsoftware.org/isdl.php |
| Python 3 + Pillow | 仅在修改图标脚本时重新生成图标（可选） | `pip install pillow` |
| ffmpeg | 录屏编码 / 导出（随程序发布） | 打包时 `tools\get_ffmpeg.ps1` 自动下载到 `tools\deps\ffmpeg`（不进仓库）；或设置 `MARKSHOT_FFMPEG` 指向本地 ffmpeg.exe |

使用者不需要安装任何依赖（.NET 运行时已打包在内）。

**在 GitHub 上自动打包**：推送版本标签即可，例如 `git tag v0.8.07` → `git push origin v0.8.07`。
`.github/workflows/release.yml` 会在 GitHub 的 Windows 机器上运行 `tools/package.ps1`，并把安装包和便携版挂到同名 Release 上；
也可以在 Actions → Release → Run workflow 手动运行（产物在该次运行的 Artifacts 里）。

**代码签名（可选）**：需要代码签名证书（.pfx）和 Windows SDK 的 signtool。设置环境变量
`MARKSHOT_SIGN_PFX`、`MARKSHOT_SIGN_PASSWORD` 后打包脚本会自动给 exe 和安装包签名；未签名时 Windows 会提示“未知发布者”。

## 安装包与更新

- `tools\build_installer.cmd`：发布并用 Inno Setup 6 生成 `dist\Markshot-Setup-<版本>.exe`（按用户安装到 `%LOCALAPPDATA%\Programs\Markshot`，不需要管理员）
- 软件始终从内置的 GitHub 发布渠道检查更新（最新 Release 里的 `Markshot-Setup-版本号.exe`），无需填写。
  设置 → 保存与识别 → 更新路径 是可选的自定义来源（文件夹或另一个 GitHub 仓库），两边取较新的版本。
  发现新版本时托盘提醒，设置左上角版本号下方出现“更新”按钮（↻ 手动检查）

## 配置

配置读取优先级：

1. exe 同目录 `config.json`（便携模式）
2. `%APPDATA%\Markshot\config.json`

保存时优先写当前生效的配置；失败则尝试另一个位置。日志固定写入 exe 同目录 `logs\app.log`。

示例（DeepSeek）：

```json
{
  "CaptureHotkey": "F1",
  "PinHotkey": "F3",
  "SaveDirectory": "",
  "OcrLanguage": "",
  "Translation": {
    "BaseUrl": "https://api.deepseek.com/v1",
    "ApiKey": "sk-...",
    "Model": "deepseek-chat",
    "TargetLanguage": "简体中文",
    "SystemPrompt": "",
    "TimeoutSeconds": 60
  }
}
```

本地 Ollama 示例：

```json
"Translation": {
  "BaseUrl": "http://127.0.0.1:11434/v1",
  "ApiKey": "",
  "Model": "qwen2.5:7b",
  "TargetLanguage": "简体中文"
}
```

字段说明：

| 字段 | 说明 |
| --- | --- |
| `CaptureHotkey` | 截图全局热键，如 `F1`、`Ctrl+1`、`Ctrl+Shift+S` |
| `PinHotkey` | 贴图剪贴板全局热键 |
| `SaveDirectory` | 保存目录，留空则为 `图片\Markshot` |
| `OcrLanguage` | 留空使用中文 PP-OCRv5 模型；填 `en` 使用英文专用识别模型 |
| `Translation.BaseUrl` | OpenAI 兼容接口根地址，需包含 `/v1`（如果服务如此） |
| `Translation.ApiKey` | 本地服务可留空 |
| `Translation.Model` | 模型名 |
| `Translation.TargetLanguage` | 默认目标语言 |
| `Translation.TimeoutSeconds` | 请求超时，10–300 秒 |

模板见 `config.sample.json`。

## 已知限制

- 主要针对单屏 / 统一缩放比例验证；混合 DPI 的多屏场景仍需联调
- 元素识别基于 UI Automation：浏览器网页、Office 等支持无障碍的程序能识别到细的元素；自绘界面（部分游戏、老程序）只能选中整窗
- 橡皮擦只擦批注，不擦截图本身；曲线工具暂无
- 贴图最多同时 20 张，关闭后只保留最近 10 张；托盘只提供“恢复最近一张”，没有历史列表
- 截图框选完成后才显示工具栏；拖拽过程中按住 `空格` 可移动选区
- 颜色条改为圆形色块：最左侧为带彩色外环的自定义色，点开后使用 HSV 色板、色相/透明度滑条、Hex 与透明度百分比
- 取色窗口支持分辨率色板、圆形滑点、Hex/百分比输入与取色器
- 贴图快捷键：`Q` 左右对称、`W` 上下对称、`E` 逆时针 90°、`F` 还原（均可在设置修改）
- 选中元素时滚轮可直接调粗细/字号；鼠标移到调整框边线或手柄会变成对应缩放光标
- 截图拖动/调整边框时放大镜保持显示，松手后隐藏
- 自定义颜色只在当前进程内记忆，不写入配置
- 录屏的真实画面 / 系统声音 / 麦克风需在桌面上手动验证（自动测试用合成画面）
- PP-OCRv5 对极小字号、低对比度和艺术字仍可能误识；版面按文字框位置重建（行、列、缩进），合并单元格等复杂表格不做结构分析
- 翻译按整段文本处理，暂不支持把译文按原版式回填图片
- 保存失败、剪贴板被占用等异常只写日志或弹窗，没有统一的重试中心
