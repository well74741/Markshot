## 本次 v0.2.1 修复

- 设置里的快捷键改为**按键录制框**：点击后直接按组合键，不再要求手输字符串。
- 支持 `F1–F24`、字母、数字、方向键、`Space/Enter/Tab/Backspace/Delete/Insert/Home/End/PageUp/PageDown/PrintScreen` 等。
- 设置窗口打开时**临时注销全局热键**，避免按 `F1` 反而弹出截图。
- 增加“**手动输入**”开关：组合键被系统/其他软件占用、录不进去时，可直接键入 `Ctrl+Shift+S`。
- 保存时统一校验并规范化，例如 `ctrl+shift+s` → `Ctrl+Shift+S`。

## 建议的下一轮（选 2–3 个）

1. **窗口/控件检测 + 放大镜/取色器** — 截图工具最影响“专业感”的两块，M。
2. **批注二次编辑 + 橡皮擦 + 直线/折线** — 减少“画错只能重来”，M。
3. **贴图历史持久化 + 分组 + 鼠标穿透** — 贴图从“临时看”变成“工作台”，M。
4. **译文原位覆盖（图片到图片）** — 翻译功能真正的差异化，L。
5. **长截图** — 你之前排除，但如果目标是替代 PixPin，这是最大缺口，L。
6. **保存 WebP/PDF + 开机启动** — 低成本高感知，S。

> 我的建议顺序：先 1，再 2，再 4；3 和 6 可以并行做。
