# Markshot 功能盘点与路线图

> 基线：v0.7.0（2026-10-31）。图例：✅ 已实现　◐ 部分实现　— 未实现
> 工作量按个人项目估算：S < 1 天，M 1–3 天，L > 3 天。

## v0.7.0 已完成

- **主轨合并**：删除选择按钮；主栏固定为图形、画笔、箭头、文字、序号、马赛克、橡皮，按图二/图三排列并统一 30px 按钮尺寸。
- **下拉风格切换**：图形/画笔/箭头/文字/马赛克带下拉箭头，分别切换矩形/椭圆、画笔/荧光笔、箭头/直线、字号、马赛克/水印。
- **同类元素选择**：工具激活时悬停同类元素高亮，点击直接选中并继续编辑；工具再次点击取消激活，鼠标回箭头并可拖动贴图。
- **截图工具栏**：增加文字识别、关闭、贴图、保存、复制、自动翻译开关；贴图工具栏按图二保留保存和确定。
- **空白修复**：贴图工具栏不再拉伸到固定 900px，宽度贴合内容，消除右侧长空白。
- **快捷键**：标注工具默认 `B/V/E/T/S/L`，设置可改。

## v0.6.0 已完成

- **工具栏重构**：主栏合并为选择/图形/直线/画笔/马赛克/文字/序号/橡皮；激活工具后在下方展开副栏，放样式切换、填充、粗细、圆角、颜色；主栏不再常驻颜色和粗细。
- **样式合并**：矩形+椭圆、直线+箭头、画笔+荧光笔、马赛克+水印；副栏切换，默认前者。
- **选择继续编辑**：选择已创建元素后，副栏同步显示并继续修改填充/圆角/粗细/颜色，样式切换可转换元素类型。
- **空格**：绘制中按住空格整体移动当前图形；没有正在绘制的图形时，贴图内空格开关编辑工具栏；工具栏最左侧拖动块可移动工具栏。
- **视觉**：按钮去底色；自定义颜色改为彩色圆；贴图编辑去掉无用的关闭按钮；新增矩形圆角/填充、水印工具。
- **快捷键**：标注工具默认 `B/V/E/T/S/L`，设置里可改。

## v0.5.0 已完成

- **贴图内联编辑**：按 `空格` 不再新开窗口，工具栏直接贴在图片下方，工具、颜色、粗细与截图工具栏一致；`Ctrl+S` / ✓ 写回。
- **图标与光标**：工具/操作按钮改为矢量图标；新增自定义颜色；各工具有独立十字光标（带工具字母徽标）。
- **交互参考**：画笔改为中点二次贝塞尔平滑；矩形/椭圆 `Shift` 约束正方形/正圆，直线/箭头 `Shift` 吸附 45°；文字用 I 型光标，选择用箭头/移动光标。

## v0.4.0 已完成

- **截图交互**：框选完成后才弹出工具栏；加粗蓝色边框，边缘/手柄可拖动重设；拖拽时按住 `空格` 移动选区；完成后隐藏放大镜、光标恢复箭头。
- **工具栏**：全部改为图标按钮，笔触/图形粗细改为滑条。
- **贴图**：去掉贴图组；最多同时 20 张，关闭后保留最近 10 张历史；按 `空格` 打开贴图标注工具栏；修复透明度变黑（改为图片自身透明度）。
- **快捷键**：贴图剪贴板热键允许留空。

## 本次 v0.2.1 修复

- 设置里的快捷键改为**按键录制框**：点击后直接按组合键，不再要求手输字符串。
- 支持 `F1–F24`、字母、数字、方向键、`Space/Enter/Tab/Backspace/Delete/Insert/Home/End/PageUp/PageDown/PrintScreen` 等。
- 设置窗口打开时**临时注销全局热键**，避免按 `F1` 反而弹出截图。
- 增加“**手动输入**”开关：组合键被系统/其他软件占用、录不进去时，可直接键入 `Ctrl+Shift+S`。
- 保存时统一校验并规范化，例如 `ctrl+shift+s` → `Ctrl+Shift+S`。
