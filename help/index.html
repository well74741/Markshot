认识 Markshot

Markshot 是一款 Windows 截图工具：截图、批注、贴图、长截图、录屏、文字识别和翻译都在一个小程序里，常驻托盘，随叫随到。

截图 + 批注自动框住窗口和界面元素，矩形、箭头、序号、文字、马赛克、聚焦……画完直接复制。
贴图把截图钉在屏幕最上层，当参考、做对照；可缩放、旋转、调透明度、继续批注，图上的文字能直接选中复制。
长截图在框里滚动，网页、聊天记录、文档自动拼成一张长图，来回滚动不会重复。
文字识别与翻译本地识别，图片不离开电脑；能识别表格、符号和公式；原位翻译把选区里的文字直接换成译文。
录屏录制屏幕区域，导出 MP4 / GIF，可剪头尾、录声音、显示按键。
图片编辑器多张图片拼版、裁切、调色、抠色、变形，批注随时可改。

Markshot 启动后在任务栏右下角的托盘里（图标），右键托盘图标可以打开所有功能、设置和本帮助。 文中 加粗高亮 的是 Markshot 有特色、别的截图软件不常见的功能。

快速上手

  1. 按 F1（或单击悬浮按钮）开始截图，屏幕会变暗。
  2. 按住鼠标左键拖出要截的区域；也可以直接单击，截取鼠标下自动框住的窗口或元素。
  3. 在下方工具栏里画上批注，然后按 Enter 或点「复制」——截图就在剪贴板里了，到聊天窗口或文档里 Ctrl + V 粘贴即可。

不想要这次截图？按 Esc 或单击右键退出。拖动中途按一下右键，就撤回这一次拖动——拖选区、画图形、移动元素都一样，不用松手再撤销。

截图

自动识别窗口和元素

截图时不用精确拖动：鼠标经过的窗口、图片、文字段、按钮会被自动框住，单击就截取它。

  • 滚轮切换识别范围：向下进入更小的元素，向上回到窗口，再往上是整个屏幕；调到的档位会被记住（设置 → 识别与保存 里可以关掉「记住」）。
  • 窗口被别的窗口挡住一部分时，框的是它的完整轮廓；带阴影边框的窗口（如微信）框的是窗口本身；Markshot 自己的设置、编辑器窗口也能框住。
  • 设置 → 识别与保存 → 截图识别：可以分别关掉元素识别、窗口识别，或调整灵敏度。

套索截图（任意形状）

按住右键拖动 = 套索截图，按住 Shift 画直线段。截出的图外面是透明的，复制到支持透明的软件或贴图时就是这个形状。

调整选区

  • 拖动边框和八个手柄调整大小，拖动区域内部移动；方向键 1 像素微调，Shift + 方向键 10 像素。
  • 拖出选区时按住空格，可以移动正在画的选区（像 Photoshop 一样），松开空格继续调大小；按住 Alt 以起点为中心，按住 Shift 画正方形。
  • 拖动中按右键撤回这次拖动，选区回到拖动前的样子。
  • 左上角的尺寸标签可以直接点击输入宽高；R 载入最近用过的截图区域。
  • 圆角截图：把选区四角内侧的小圆点往里拖，或在选好区域后滚动滚轮。复制、保存和贴图都会带上圆角（Win + 鼠标截图也会沿用）。
  • 放大镜显示像素颜色，按 C 复制色值，Shift 切换 RGB / HEX；单按 Alt 显示贯通屏幕的十字辅助线。
  • Ctrl + M 切换截图里是否带鼠标指针。

批注

选好区域后，下方工具栏就是批注工具：矩形 / 椭圆、箭头 / 直线 / 折线、画笔 / 荧光笔、文字、序号 / 聚焦、马赛克 / 模糊 / 水印、橡皮擦。

  • 右键撤回：画图形、移动、缩放、旋转时还没松手，按一下右键就撤回这一步；拿着工具时右键先放下工具，再右键才是退出。
  • 画图形时按住空格，可以整体移动正在画的图形，松开继续画；按住 Alt 从中心画，Shift 画正方形 / 正圆 / 45° 线。
  • 橡皮擦「抠除」：连同图片和所有批注一起擦成透明空洞，之后画的批注也不会盖住空洞；贴图上空洞真正透明，阴影沿着空洞的形状。
  • 箭头、直线可以弯曲：选中后拖两端改方向，拖中间的点弯成曲线；序号拉出的箭头也能拖动箭头的方向。
  • 聚焦：拖出一块区域，里面保持原样、外面变暗，突出重点；马赛克、模糊可以只打码一部分。
  • 工具的样式、粗细、颜色在工具栏下方的副栏里调；带 ▾ 的按钮里有同类的其他样式，Tab 在它们之间切换。
  • 选中元素后滚动滚轮调粗细 / 字号，Ctrl + 滚轮调透明度；Delete 删除，Ctrl + Z / Ctrl + Y 撤销 / 重做（也可以按 Z / Shift + Z）。
  • 文字：选文字工具后在空白处双击开始输入，Enter 完成，Shift + Enter 换行。
  • 画笔按住 Alt 出现吸色十字，单击吸取颜色；数位板画笔有压感。
  • 工具快捷键：M 图形、L 箭头、B 画笔、T 文字、S 序号、E 橡皮、V 选择（设置里可改）。工具栏按钮可以长按拖动排序，设置 → 批注栏 里可以隐藏不常用的按钮。

贴图

贴图就是把图片钉在屏幕最上层：写文档时对照资料、比较两个版本、记住一串数字……

  • F3：把剪贴板里的图片（或文字）直接贴到屏幕上；把图片文件拖到悬浮按钮上也会贴在屏幕中央，GIF 动图会动。
  • 贴图上的文字可以直接拖选复制（本地文字识别），双击选中整行。按住 Alt 拖动则只移动贴图——这个键可以在 设置 → 快捷键 → 贴图窗口 里换成别的键；那里也可以关掉文字选择，关掉后在文字上拖动就是移动贴图。
  • 空格 打开批注工具栏，在贴图上继续画；Q / W 水平 / 垂直翻转，E 旋转，F 一步复原：转过、翻过多少次都只用一个动画回到最初的大小和方向。
  • T 切换置顶，L 锁定；右键菜单里有鼠标穿透（点击直接穿过贴图，Ctrl + Alt + M）、原位翻译、另存为等。
  • 双击复制并关闭，Esc 关闭，Shift + Esc 关闭所有贴图；关错了按 Ctrl + Alt + Z 恢复，或从托盘「贴图历史」找回（连批注一起恢复）。
  • Shift + 单击可以多选贴图，一起移动、一起关闭；拖动贴图没松手时按右键，贴图回到原位。

长截图

网页、聊天记录、长文档一屏放不下时用长截图：截图选好区域后，点工具栏的「长截图」，然后在框里滚动。

  • 向下、向上都能拼接（聊天窗口从底部往上翻也可以）；来回滚动不会重复拼接，滚轮一次滚很多也能接上。
  • 框里有固定的侧栏、滚动条也能识别，结果里会自动去掉它们；固定的页头、底栏只保留一份。屏幕缩放（125%、150%）和平滑滚动的页面也能拼接。
  • 工具条上的 文字识别 按钮直接识别整张长图里的文字（长图会分段识别，从头到尾都读得到）。
  • 滚得太快、两次画面之间没有重叠时，预览窗会提示「跟丢了」：往回滚一点再慢一些即可接上。
  • Tab 切换竖向 / 横向，Enter 进入图片编辑器，Esc 取消回到截图。

文字识别与翻译

文字识别在本机运行（PP-OCRv5 模型），图片不会上传。截图工具栏、悬浮按钮、Win + 左键、长截图工具条都可以打开文字识别。

  • 识别表格：有没有表格线都可以，同一行、同一列对齐的内容会还原成表格；「表格」开关切换表格样式和文字样式，复制时同时带表格格式。
  • 保留排版：同一行的文字合成一行，缩进和段落空行保留；分栏的文章按栏阅读（先读完左栏再读右栏），不会左右混在一起。
  • 符号和公式：π、±、≤、≥、≠、≈、√、∑、°、℃、上标 ² 等常见符号都能识别；上下排的分数会写成 (a+b)/(2c) 这样的一行。复杂的多层公式目前只能识别出其中的文字。
  • 识别时会同时读取二维码、条形码，识别出的链接可以直接点开。
  • 导出：文字识别窗口的「导出」把结果存成 Excel（表格逐格，数字可直接计算）、Markdown（表格转成 Markdown 表格）或文本。
  • 公式识别（扩展模型）：在 设置 → 识别与保存 → 文字识别 → 扩展模型 里下载「公式识别」（约 120 MB，不随安装包）。装好后文字识别窗口出现「公式」按钮，把公式图片识别成 LaTeX，可粘贴到 Word、Markdown、论文里；再点一下回到文字结果。

原位翻译

  • 原位翻译：右上角的语言标签可以切换目标语言，点 ✕ 关闭翻译回到原文；贴图的右键菜单里也有「原位翻译」。
  • 「文字识别」窗口左边是原文（可编辑），右边是译文，两边都可以复制或贴到屏幕上。
  • 翻译需要在 设置 → 翻译 里填写一个 OpenAI 兼容的接口（DeepSeek、通义、Moonshot、Ollama 等）和 API Key；也可以下载 离线翻译包，不联网也能翻译。

Win + 鼠标

不进入截图界面：按住 Win 键直接用鼠标在屏幕上划一个区域。

  • 默认：左键 = 识别文字，中键 = 贴图，右键 = 复制；设置 → 快捷键 里可以给每个键换成别的动作或关闭。
  • 划的时候按住 空格 可以移动区域，按右键取消；区域沿用截图的圆角设置。

悬浮按钮

  • 单击的动作可以在设置里改（截图、文字识别、录屏……）；拖动按钮可以放到任何位置，会记住。
  • 任何程序复制了图片，按钮上都会滑过一张缩略图，确认已经复制成功。
  • 把图片文件拖到按钮上，直接贴到屏幕中央。
  • 右键菜单：添加贴图、粘贴剪贴板、关闭 / 打开所有贴图、鼠标穿透、全屏时自动隐藏、设置。
  • 按钮图标可以换成自己的图片或 GIF（设置 → 样式 → 悬浮按钮）。

录屏

  • 托盘菜单「录屏」、悬浮按钮或截图工具栏的录屏按钮打开；拖边框移动、拖把手调大小，框线画在区域外面，不会录进视频。
  • 工具栏可以选帧率、尺寸、倒计时，录系统声音和麦克风；操作录制把按下的键盘 / 鼠标键显示在画面里，一起录进视频。
  • 停止后原地预览：拖动时间条剪掉头尾，调倍速，保存为 MP4 或 GIF，或 直接复制视频文件 粘贴到聊天里。
  • 工具栏开始按钮左边的「截屏」可以随时截下录制区域。

图片编辑器

  • 托盘「图片编辑器…」、截图 / 贴图工具栏的编辑按钮、长截图的「编辑」打开；也可以设为图片的打开方式。
  • 图片和批注都是可以再改的元素：多张图片拼版、排层、对齐，批注随时可改。
  • 裁切（矩形 / 手绘路径）、梯形校正、网格变形、旋转镜像、调色和曲线、抠色与替换颜色。
  • 保存为 PNG / JPEG / WebP / BMP / TIFF，或「贴到屏幕」。

使用案例

① 给同事指出界面问题

F1 框住出问题的窗口 → 矩形框住位置 → 箭头 + 序号标出步骤 → 文字写说明 → Enter 复制，到聊天里 Ctrl + V。

② 对照资料写文档

截下参考资料后按 F3 贴图，Ctrl + 滚轮调到半透明，开「鼠标穿透」，贴图就像一层描图纸，下面的软件照常操作。

③ 保存一整段聊天记录

框住聊天记录区域 → 长截图 → 从底部往上滚到开头 → 复制。往上翻、来回翻都不会拼重复。

④ 看懂外文软件

框住英文界面，打开「原位翻译」：每个按钮、标签原地换成中文，贴图后还能边看边操作。

⑤ 把图片里的表格变成 Excel

按住 Win 用左键划过表格 → 文字识别窗口里以表格显示 → 复制 → 在 Excel 里粘贴，行列都在。

⑥ 打码后再发出去

截图后用马赛克或模糊盖住手机号、头像；用「聚焦」把要看的地方留亮、周围变暗。

⑦ 录一段操作演示

框住区域 → 录屏 → 打开「操作录制」显示按键 → 停止后剪掉头尾 → 保存为 GIF 发给别人。

⑧ 抠出一个不规则的图形

按住右键沿着图形画一圈（套索截图），或截图后用橡皮擦「抠除」擦掉不要的部分 → 贴图，外面是透明的。

⑨ 复制论文里的公式和符号

框住公式所在的段落 → 文字识别：π、±、√、∑ 等符号原样识别，分数写成一行，可以直接粘贴编辑。

常见问题

按 F1 没反应？

F1 可能被别的软件占用了。打开 设置 → 快捷键，点输入框后按下新的组合键；托盘图标中键单击也能直接截图。

长截图提示「跟丢了」或「无法拼接」？

两次画面之间没有重叠时会跟丢：往回滚一点、再滚慢一些就能接上。框只框能滚动的部分效果最好；如果框里只有动画或视频在变，内容没有整体移动，就无法拼接。

贴图上一拖就选中了文字，不想要？

拖动时按住 Alt；或在 设置 → 快捷键 → 贴图窗口 里关掉「贴图上的文字可直接拖选复制」，也可以把 Alt 换成别的键。

能识别复杂公式吗？

日常文字识别能读出常见符号和简单分数；多层的公式请下载「公式识别」扩展模型（设置 → 识别与保存），用文字识别窗口的「公式」按钮识别成 LaTeX。

识别出的表格不对？

表格按对齐的行列还原，合并单元格、斜线表头可能会拆错；关掉「表格」开关看文字，或复制后在 Excel 里稍作调整。

翻译显示失败？

翻译需要在 设置 → 翻译 填写接口地址和 API Key，或下载离线翻译包。文字识别不需要联网。

第一次文字识别比较慢？

第一次要加载识别模型（约 1–2 秒），之后就很快了；很长的长截图会分段识别，稍等几秒。

截图里会有悬浮按钮吗？

不会。截图时悬浮按钮自动隐藏（设置里可以改为一直显示）。

设置改了没生效？

设置里的修改要点右下角「保存」才生效；主题、悬浮按钮等是即时预览，不保存关闭时会还原。

出了问题怎么反馈？

托盘菜单「导出诊断信息」会把日志和配置（不含 API Key）打包到桌面，发给作者即可（联系方式见下方「关于」）。
